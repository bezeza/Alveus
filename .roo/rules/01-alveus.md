# Alveus rules for Roo Code

Read and follow the repository-root `AGENTS.md` before every task. It is the
canonical policy for all coding agents. Preserve existing changes, work on a
dedicated branch, add a dated `docs/DEVELOPMENT_LOG.md` entry for every
implementation PR, run relevant CI-equivalent checks, and report exact results.
Never merge or perform desktop/system-changing actions without explicit user
approval. Never log secrets or user file contents.
