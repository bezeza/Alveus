# Alveus Dock — repository snapshot

This branch preserves the Alveus Dock 0.1.2 source archive separately from the Alveus mainline.

- Branch: `alveus-dock`
- Snapshot: `alveus-dock-0.1.2-source.zip`
- Archive contains the QML Plasma applet, Fedora RPM spec, scripts, GitHub Actions workflow, changelog, development log, logging guide and roadmap.
- This is an interim archive snapshot in the Alveus repository. A dedicated `bezeza/alveus-dock` repository is preferable for ongoing development and releases.

The archive is a backup snapshot, not a claim that the applet has passed runtime testing. QML validation and Fedora KDE Plasma 6.8.2 testing remain pending.
